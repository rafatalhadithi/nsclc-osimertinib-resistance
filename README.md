# Osimertinib Resistance in NSCLC: Multi-Modal Transcriptomic Pipeline

This repository contains the computational pipeline used to investigate the transcriptomic mechanisms of Osimertinib resistance and metastatic lineage plasticity in Non-Small Cell Lung Cancer (NSCLC). 

## Overview
By integrating single-cell RNA sequencing (scRNA-seq), spatial transcriptomics, and machine learning, this framework maps resistance evolution across diverse structural states. A Nested Patient-Level Cross-Validated Random Forest classifier highlights **SCGB3A2** and **MUC1** as robust predictors of acquired resistance. The pipeline also maps a localized epigenetic seesaw between EZH2 and the HOXC genomic locus, demonstrating via *in silico* pseudo-bulking how traditional bulk sequencing methodologies mathematically mask these spatial correlations through Simpson’s Paradox. Finally, the targets are externally validated using a longitudinal single-cell clinical cohort (Treatment Naïve vs. Residual Disease vs. Progressive Disease).

## Pipeline Execution Details
Run the scripts from the `notebooks/` directory in the sequential order provided below:

### `01_preprocess_GSE131907.py`
**Preprocessing & Quality Control:** Ingests raw matrices, applies strict biological filtering (mitochondrial/doublet thresholds), normalizes data, and calculates high-dimensional embeddings (PCA/UMAP/Leiden). Annotates immune/tumor cell populations.
* **Input:** `GSE131907_RAW_merged.h5ad`
* **Outputs:** `GSE131907_FINAL_ANNOTATED.h5ad` [Zenodo], `marker_genes_complete.csv`, Figure 1, Supp Fig S1, Supp Fig S2

### `02_preprocess_Maynard.py`
**Validation Cohort Preparation:** Standardizes the external Maynard longitudinal dataset. Extracts clinical TN, RD, and PD stages, deduplicates metadata, and filters for tumor cells.
* **Inputs:** `S01_metacells.csv`, `S01_datafinal.csv`
* **Output:** `maynard_annotated.h5ad`

### `03_ML_Patient_CV.py`
**Confounder-Free Biomarker Discovery:** Isolates the epithelial tumor fraction and utilizes a Nested Patient-Level GroupKFold CV Random Forest classifier to prevent data leakage. Identifies top predictive features (e.g., MUC1, SCGB3A2).
* **Input:** `GSE131907_FINAL_ANNOTATED.h5ad`
* **Outputs:** `Reviewer_Patient_Level_CV_Metrics.csv`, `Reviewer_Feature_Importances.csv`, Figure 5

### `04_PseudoBulk_GSEA.py`
**Pathway Enrichment:** Uses `decoupler` to aggregate cells by patient to eliminate pseudo-replication inflation. Runs continuous Log2FC-ranked GSEA against MSigDB Hallmark signatures for both cohorts.
* **Inputs:** `GSE131907_FINAL_ANNOTATED.h5ad`, `maynard_annotated.h5ad`
* **Outputs:** `Updated_Supplementary_Data_1_DGE.csv`, `Figure_2_Pathway_Data_GSEA.csv`, `Maynard_PD_vs_TN_Hallmark_Summary.csv`, Figure 2

### `05_PAGA_Trajectory.py`
**Evolutionary Lineage:** Generates unsupervised PAGA (Partition-based Graph Abstraction) evolutionary trajectories to prove root-independent lineage flow.
* **Input:** `GSE131907_FINAL_ANNOTATED.h5ad`
* **Outputs:** `Reviewer_PAGA_Evolutionary_Connectivity.csv`, Figure 3

### `06_Squidpy_Immune_Evasion.py`
**Cell-Cell Communication:** Replaces descriptive co-expression with a 1,000-permutation statistical framework via `squidpy` to validate THBS1-CD47 and PTPN11-PDCD1 immune evasion interactions.
* **Input:** `GSE131907_FINAL_ANNOTATED.h5ad`
* **Outputs:** `Supplementary_Table_S4_Permutation_Pvalues.csv`, `Supplementary_Table_S5_Permutation_Means.csv`, Figure 4

### `07_Spatial_Simpson_Paradox.py`
**Spatial Niche Mapping:** Processes 10x Visium spatial transcriptomics to map the physical architecture of the EZH2-HOXC seesaw. Simulates pseudo-bulk spatial masking to demonstrate Simpson's Paradox.
* **Inputs:** GSE267960 Visium Spatial H5 files
* **Outputs:** `Epigenetic_Driver_Correlations.csv`, `Pseudo_Bulk_Masking_Simulation.csv`, Supp Fig S3, Supp Fig S4

### `08_PPI_Network_Generator.py`
**Network Architecture:** Constructs the Protein-Protein Interaction (PPI) network for the identified ML biomarkers via the STRING API, generating a Cytoscape-ready topology.
* **Input:** `Reviewer_Feature_Importances.csv`
* **Outputs:** `Figure_7_PPI_Edges_Updated.csv`, `Figure_7_PPI_Network.graphml`, Figure 7

### `09_TCGA_Survival_Prep.py`
**Clinical Stratification Prep:** Parses TCGA-LUAD expression and clinical metadata, filters for EGFR-mutant patients, and calculates Composite Z-Scores of the MUC1/SCGB3A2 biomarker signature.
* **Inputs:** TCGA-LUAD text files, `Reviewer_Feature_Importances.csv`
* **Output:** `Figure_8_Survival_Data.csv`

### `10_Plot_Survival_R.R`
**Kaplan-Meier Survival Plotting:** R script utilizing `survminer` to generate high-impact Progression-Free Survival (PFS) curves with at-risk tables.
* **Input:** `Figure_8_Survival_Data.csv`
* **Outputs:** Figure 8 (PFS Plot), Figure 6 (OS Plot)
